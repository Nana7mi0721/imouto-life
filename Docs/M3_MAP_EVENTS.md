# M3-H 地图事件冒烟与注册地图属性（task-14）

本文件由 `crates/wolf-game/tests/m3_map_events.rs` 的实测结果生成，记录本作（`Imouto! Life ~Monochrome~ zh-CN Ver.`）**5 张注册地图**的结构属性，以及 `SampleMapA` 全部 35 个地图事件的 headless 冒烟结果。m1 已覆盖标题→CE42→Map003→SampleMapA / CE14 读档链；本文件从 `.mps` 一侧验证地图几何、页激活条件与页执行。

## 方法

- 数据根：`WOLF_DATA_ROOT=work/Data`（相对路径按仓库根解析）；`work/Data/MapData` 下仅有 8 个 `.mps`：Dungeon、Map002、Map003、Map024、Map031、SampleMapA、SampleMapB、TitleMap。本任务只覆盖注册的 5 张。
- 结构断言：`wolf_format::mps::Map::parse` 解析 `.mps`，用 `Map::stats()`（`SlotStats`）读总槽数/空槽数（opcode 0 = 空指令）与 opcode 集合，直接读 `width/height/events/pages`。
- 页激活：读 `Save/SaveData01.sav`，用 `wolf_game::savegame::read_save` 拿 `SavePart3` row0 的 302 个普通变量（`part3.normal_var(i)`）+ Sys3/Sys4 选项锚点，构造与真实读档一致的变量上下文，对每张图每个事件调用 `MapEvent::active_page_index(get_variable)`（条件变量是 WOLF magic，用 `wolf_vm::Magic::decode` 分类为普通/系统/自身/字面量后取值）。断言：**不 panic**，且返回的活动页下标恒 < 该事件页数。
- 事件冒烟：对 `SampleMapA` 35 个事件，每个事件用**全新** `Game::new`（已内置全部公共事件、数据库与 `System.sav` 基线），`auto_advance=true`，`game.start_map_event(&map, id)` 只启动该事件第一页（隔离运行，避免 event0 开场白污染首行），跑 **bounded 120 帧**，记录 started / messages / pictures / `stats.warnings`；**warnings>0 即 fail**。
- 地图切换：从 `.mps` 侧断言 Map003 的新游戏钩子页含 opcode 130（teleport 到 SampleMapA）；再 boot 新游戏（标题 menu1，`auto_choice`），断言运行诊断含 `130 Teleport: MapData/Map003.mps` 与 `130 Teleport: MapData/SampleMapA.mps`、`warnings==0`。读档 HUD 正常由 m1 断言，本文件不重复。
- 复现：`WOLF_DATA_ROOT=work/Data cargo test -q -p wolf-game --test m3_map_events`（约 8–10s；缺数据则全部 skip、exit 0）。

## 需上下文/参数的事件（只冒烟、不硬跑分支）

- **无可见输出（隔离运行）**：8、11、16、17、18、20、24、26、34、35。多为清理 handler 或大型 UI 状态机，需已打开的菜单/已进入的对话才有实际分支；本测试只证明它们可启动、可空转 120 帧且 `warnings==0`。
- **调用公共事件、依赖妹妹状态**：1、2、3、4、25（首条「…什么？」来自被调用的公共事件）。
- **需玩家按键/选项**：12、13、21、22、28 等 trig0 事件（隔离时停在等待选项，属正常）。
- **自启动（parallel/autorun）**：6、14、19、20、23、26、27、29、31、32 等 trig2 事件，随地图载入自动运行。
- 类比 m3-fixer 发现的 CE212（带参辅助子程序，单独跑会无限循环）：本图暂未发现“单独跑即无限循环”的地图事件（全部在 120 帧 bounded 内正常返回、warnings=0）；但 16/17/18 等超大槽数状态机同样属于“需 UI 上下文”的 handler，不强行驱动其分支。

## 结论

- 5 张注册地图尺寸/事件数/页数/槽数/空槽数/opcode 集均与实测一致；`Map::parse` + `stats()` 稳定。
- 每张图每个事件在 load 存档变量上下文下 `active_page_index` 零 panic、活动页下标恒在界内。
- SampleMapA 35 个事件全部 `started`、bounded 120 帧内 `warnings==0`；无需修改 src。
- 地图切换（标题新游戏 → Map003 opcode130 → SampleMapA）由数据（Map003 钩子页含 opcode130）与运行诊断双重佐证；读档 HUD 由 m1 覆盖，未重复。
