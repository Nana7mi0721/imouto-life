# M3-E 自有事件冒烟与事件地图（task-11）

本文件由 `crates/wolf-game/tests/m3_event_smoke.rs` 的实测输出生成，记录本作（`Imouto! Life ~Monochrome~ zh-CN Ver.`）**自有**公共事件 CE212..=CE303（共 92 个；CE0..211 为 WOLF 模板）在“读档卧室”状态下的 headless 冒烟结果。

## 方法

- 数据根：`WOLF_DATA_ROOT=work/Data`（相对路径按仓库根解析）。
- 每个事件使用**全新** `Game`：`Game::new` → `start_engine_events()` → `load_save(Save/SaveData01.sav)`（恢复 800 普通变量、vardb 覆盖、Sys3/4 选项锚点与整个图片层）→ 预热 5 帧 → 校验卧室 HUD（槽位 230 的可见文本含“行动力”）→ `screen.clear()` → `start_event(id)`。
- 运行时 `auto_advance=true`、`auto_choice=true`、`auto_choice_delay=2`，帧预算默认 180 帧；事件主实例结束即提前停止。
- 每帧采集：消息文本（首次出现去重）、选项（首次出现）、正槽位图片、声音命令数；结束时对比 `stats.warnings` 与 `game.diagnostics` 的增量。
- 复现：`WOLF_DATA_ROOT=work/Data cargo test -q -p wolf-game --test m3_event_smoke -- --nocapture`（约 20s；缺数据则跳过）。

## 覆盖结论

- 纳入 92 个事件；其中 **91 个独立冒烟执行**，**1 个（CE212）因需调用上下文而仅记录、不执行**。
- 91 个执行事件：started=true，frames>0=true，warnings==0=true（全部通过）；其中 71 个在预算内自然结束，20 个为常驻/等待输入的循环，在 180 帧预算内未结束（属正常，非失败）。
- 每个事件执行前基线 warnings 均为 0（wbase=0：全部）。
- 引擎常驻/自动事件（214, 216, 241, 261, 269, 270, 271）已由 `start_engine_events()` 提供上下文；测试中再次显式启动它们仅作冒烟，均正常结束或按预期运行。

### 需上下文事件：CE212

CE212「フキダシ会話文表示」（气泡对话文本显示）**不是自包含事件**，而是被其它事件**带参数调用**的辅助子程序。其脚本在 pc62 处用 opcode170 进入循环，pc63 用 opcode112 比较 `self1600006` / `self1600008` 作为退出条件；当以默认 `self=0` 独立启动时退出条件永不成立，形成**无限循环**（同一帧内持续执行，表现为测试挂死，而非 warning）。因此本测试将其标注为 CONTEXT-DEPENDENT 并**不独立运行**；其真实行为需由调用方传入 self 变量后观察。此外 `wolf-cli run --event 212` 同样不适用。
