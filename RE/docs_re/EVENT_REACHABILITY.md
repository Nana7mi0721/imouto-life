# 事件可达性与视觉回归（task-9）

本文件记录两项自动化验收流程的实测结果：

1. **逐事件可达性**：把 350 个公共事件 + 5 张注册地图的 40 个地图事件全部真正启动一遍，
   用「读档卧室」这一与实机一致的运行态驱动 180 帧，判定每个事件是自然结束、常驻、

   非黑像素数，任何渲染/文本/纹理改动都会让基线变化。

两个测试都是**真跑**的结果（命令见 §7），缺数据时 skip 并 exit 0。

## 2. 方法

### 2.1 事件可达性（`crates/wolf-game/tests/m14_event_reachability.rs`）

- **运行态**：与实机一致 —— `Game::new(data_root)` → `start_engine_events()` →
  `load_save(work/Data/Save/SaveData01.sav)` → 先跑 5 帧稳定。该状态即卧室、白天。
- **驱动**：`auto_advance = true`、`auto_choice = true`、`auto_choice_delay = 2`，
  即「消息自动推进 + 选项自动选第一个」，把需要玩家输入的菜单也跑过去。
- **判定**：每帧读 `FrameOutcome.report.steps`；
  - `steps >= DEFAULT_BUDGET`（`crates/wolf-vm/src/exec.rs` 的 `200_000`）连续 3 帧 → `spin`；
  - 主实例从 `vm.instance(id)` 消失 → `ended`；
  - 跑满 180 帧（`M14_FRAMES` 可覆盖）仍在 → `running`；
  - `start_event` 返回 None → `not_started`。
- **采集**：消息文本（去重）、首次选项集合、屏幕上编号大于 0 的图片、声音命令数、
  `stats.warnings` 与 `diagnostics` 的增量、以及地图事件的页条件。
- **地图事件**：直接 `wolf_format::mps::Map::parse` 读 mps，用存档变量构造 getter 求
  `MapEvent::active_page_index`；有活动页则把该页 `commands` 经
  `Program::from_slots(event.id, &event.name, page.commands.clone())` 交给
  `vm.start_program`。**不模拟触发器、接触、地图移动**，只验证「脚本本身能不能跑完」。
- **公共事件**：不注入 self/字符串参数（CE212 因此自旋，见 §4.1）。
- 每个事件都用一个**全新的 `Game`**，避免上一个事件残留的变量/图片污染判定；
  启动事件前先 `game.screen.clear()`，所以**存档里原有的 94 张图片不会被算进事件的
  `pictures` 列**（实测所有事件的最大图片数是 64 < 94，见 §4.5）。
- 存档槽可用 `M14_SAVE` 覆盖（默认 `SaveData01.sav`），报告名可用 `M14_REPORT` 覆盖
  （默认 `report.tsv`），用于换一个状态复核；非默认槽若没有卧室 HUD 只提示不报错。
- 390 个事件在 debug 下约 30–36 s。

### 2.2 视觉回归（`crates/wolf-cli/tests/m14_visual_regression.rs`）

- 黑盒 `Command::new(env!("CARGO_BIN_EXE_wolf-cli"))`，`current_dir(repo_root)`，
  `env_remove("WOLF_GAME_DIR")`（否则字体源被外部目录覆盖，文字全部消失、基线全变）。
- 所有场景共用 `static CAPTURE_LOCK: Mutex<()>` 串行执行 —— 离屏 wgpu 初始化不能并发。
- 输出 `work/out/m14_visual/<scene>.png` 与同名 `.log`；PNG 用 `image` 解码后断言
  **1024×576** 且非黑像素数与 stdout 报告值一致（防止「报告说画了、实际没写盘」）。
- 基线数值写在测试内的 `BASELINES` 常量数组，字段：frames / peak_coroutines /
  pictures_live / textured_quads / text_pictures / choice_open / choice_options /
  atlas_images / text_items / text_glyphs / text_lines / nonblack / messages / choices，
  另断言 `warnings == 0`。
- 确定性验证：同场景连拍两次，5 张 PNG 的 sha256 两两相同
  （title `561a35fc…`、map_idle `ba020326…`、saveui `fa673d5c…`、
  day_command `e2985af7…`、hud `ba7d0bd2…`）。

  触发时机、移动路线、接触判定都未覆盖（属另一层验收）。
