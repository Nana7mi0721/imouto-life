# M3-AK 自有事件真实输入可达性审计（task-41）

本文件由 `crates/wolf-game/tests/m3_event_inputs.rs` 的实测输出生成，记录本作**自有**公共事件 CE212..=CE303（共 92 个）在**真实按键注入**下的可达性。`docs/M3_EVENT_MAP.md`（task-11）只验证事件能启动、跑帧、warnings==0；本审计进一步用输入驱动，看事件能否真的推进/结束，或如实记录它在等什么输入。

## 方法

- 数据根 `WOLF_DATA_ROOT=work/Data`；缺数据整测跳过、exit 0。
- 每个事件全新 `Game::new` → `start_engine_events()` → `load_save(Save/SaveData01.sav)` → 预热 5 帧 → 校验卧室 HUD → `screen.clear()` → `start_event(id)`；指针移到 (-1,-1) 防止注入的 OK 触发地图按钮。
- **真实输入**：`auto_advance=false`、`auto_choice=false`；每帧给 `game.key_bits` 赋 28 帧循环里的值（决定/下/上/サブ/キャンセル 轮流按下再松开），引擎在帧末把按键存入 `previous_keys`，因此脚本看到的是「新鲜按下」。消息推进与 opcode-102 选项导航全部由注入按键驱动。
- 帧预算默认 1800 帧、单事件墙钟上限 6s；连续 900 帧无可观测变化判为停滞。事件主实例消失即 `ended`。
- 结果分类：**自然结束**（ended）/ **等待输入-常驻**（stalled，已显示消息/选项/图片，属正常交互循环）/ **超时**（timeout）/ **CONTEXT-DEPENDENT**（需调用方带参，不独立跑）。

## 覆盖结论

- 纳入 92 个事件：**独立运行 91 个**，**1 个（CE212）CONTEXT-DEPENDENT 未独立运行**。
- 91 个运行事件：全部 started=true、frames>0、warnings==0、无缺失上下文；其中 **84 个在输入下自然结束**（task-11 冒烟仅 71 个结束），**7 个为可交互的等待输入循环**（都显示了消息/选项/画面，属正常，不是死循环也不是失败），0 个超时。
- 无事件需要额外 `set_var` 前置注入：全部 91 个在「引擎常驻事件 + SaveData01」上下文直接 start_event 即可运行；停滞的 7 个是昼夜流程/演出的顶层交互循环，等待玩家在菜单里做出终止性选择（如选择“睡觉/不买”），并非缺少变量。

### 唯一需上下文事件：CE212

CE212「フキダシ会話文表示」是被其它事件**带参调用**的气泡文辅助子程序：pc62 用 opcode170 进循环、pc63 用 opcode112 比较 `self1600006`/`self1600008` 作退出条件；默认 `self=0` 时退出条件永不成立，单独跑即无限循环。故标 CONTEXT-DEPENDENT 不独立运行；其真实行为须由调用方传 self 后观察（与 task-11 结论一致）。
