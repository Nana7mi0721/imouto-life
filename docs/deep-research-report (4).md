# 妹！生活 ～単色～ 机制考证报告

## ① 结论摘要  
- **** 主角身份分为「学生」「フリーター」「社会人」「ダメ人間」四种，不同身份对应不同基础属性：学生基础行动力60、初始金钱3000–6000、收入低、就寝24点，仅放学后可行动；フリーター行动力40、金钱8000–12000、收入中、就寝23点，白天有1次自由行动机会；社会人行动力30、金钱30000–50000、收入高（约每周40000）、就寝23点，下班后可行动；ダメ人間行动力25、金钱1000、收入低、就寝24点，白天有3次自由行动机会。  
- **** 行动力上限由身份决定（25~60），可被角色特性或道具提升（如“体力自慢”+10行动力、「ダンベル」+5行动力上限）；行动力上限理论最大99。常见行动消耗：上班消耗30点行动力。  
- **** 时间段划分上，各身份就寝时间不同（社会人与フリーター23点、学生与ダメ人间24点）；平日夜间“夜袭”可进行至凌晨2点（周末无时限）。根据身份不同，白天免费行动次数不同（详见上条），一般每执行一次行动则推进时间。夜深或行动力耗尽后自动进入睡眠，结算状态并推进到下一天。  
- **** 角色的基本性格特性（如「ドスケベ」「むっつり」等）在开局小测试中决定，并对行动力、信赖等有加成或减成；妹妹的状态指标包括信赖、兴趣、感度和心情五种，会随时间与行为变化。  
- **** 游戏流程大致为：起床→（根据星期与身份进入学校/工作）→放学/下班后回家→晚间可选择锻炼、学习、约会等→深夜若体力/兴趣充足可继续触发事件→进入就寝。时间推进由玩家选择行动触发或自动到达就寝时间，未见证具体指令。  

## ② 机制/流程 Step-by-Step  
1. **晨醒与状态刷新**：每天早晨自动进入起床流程，刷新角色状态。妹妹的好感（信頼）、性兴趣（興味）、感度会每天少量下降；角色每日初始行动力恢复到上限（睡眠时间越长，第二天恢复越多）。开局根据设定好的问卷确定主角身份（职业）与特性。  
2. **日间阶段**：根据身份不同选择行程：  
   - **学生**：上午上学，放学（通常傍晚）后开始自由活动；日间无法行动。  
   - **フリーター**：日间有1次自由行动机会（可用于购物、锻炼等），其余时间自由支配；无需固定上班。  
   - **社会人**：工作日白天固定上班（消耗行动力30、身心疲惫），下班后才能进行其他行动。每周末发放薪水（约4万/周），并补充到金钱。  
   - **ダメ人間**：无固定职业，白天拥有3次自由行动机会，可以随意工作或休息。  
   每次行动（如购物、锻炼、约会）会消耗一定行动力，行程结束后可能触发事件或返回家中。  
3. **傍晚／夜间**：日间行程结束后，主角返回家中开始“回家菜单”。平日回家路上可购买少量物品（茶叶、饮料等），到家后可与妹妹互动、做晚餐、锻炼、学习等。夜间可继续陪伴妹妹、玩游戏等。特殊行动：上班、回家等活动消耗行动力；服用道具可回复行动力或影响睡觉时间。平日夜晚最晚到凌晨2点为“深夜”截止点，周五周六则不受限制，可持续至妹妹和主角均疲惫为止。  
4. **深夜／就寝**：达到身份对应就寝时间（社会人/フリーター23点，学生/ダメ人間24点）或行动力耗尽后进入就寝流程。系统结算：日期加1；妹妹若在“睡眠中”状态，则次日信赖会下降。角色行动力恢复至上限（早睡恢复更多），精力等数值可能重置。金钱保留并累计收入；无证据表示减少。*（时间推进方式：每次活动结束或达就寝点自动跳到下日。）*
