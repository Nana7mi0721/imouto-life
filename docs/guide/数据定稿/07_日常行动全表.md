- 坐标 `CE<编号>@<pc>`（id 0 基 `0..349`）；变量写 `varN`；统一 8 列表：| 对象/ID | 名称 | 条件或数值 | 变量ID | 脚本证据 | 攻略观测值 | 判定 | 备注 |
- 判定图例（7 种）：`✅一致`、`✎以脚本为准`、`◐部分/尺度不同`、`—脚本未定位`、`⊘非本作`、`U未验证`、`S/T/G/U`。本层主表判定按 `ce_entry_conditions_v2.tsv` 的 `verdict` 映射：`清楚→✅一致`、`部分清楚→◐部分/尺度不同`、`⊘非玩法事件→⊘非本作`、`缺→—脚本未定位`。
- **成人内容一律中性技术表述**：只写变量 ID / 事件 ID / 阈值 / 状态机术语 / 增量，不写场景描写、不引用露骨原文（AGENTS.md §6）。
