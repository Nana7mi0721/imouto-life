- **op111 契约**（`00_说明与口径.md` §2）：首真命中的**有序分档**（第 i 个真 → `case#(i+1)`），**非逻辑与**；`n=a[0]&0xF`、bit4=has_else；三元组 `(var,value,op)`；操作符 `0>,1>=,2==,3<=,4<,5!=,6&`；**`17/18/19` = 移植库 `==` 兜底、零售原语义 U**；**`a[0]=17/18/19` 是「n+has_else 头字节」不是操作符**。只有多个**单条件 op111 层叠**才是 AND。
- **成人内容一律中性技术表述**：只写变量 ID / 事件 ID / 阈值 / 状态机术语 / 增量，不写场景描写、不引用露骨原文（AGENTS.md §6）。
- **三条铁律**：① 攻略值 ≠ 脚本值一律用脚本值；② `U`/`—`/`◐` 项正文只写「资料不足/待核」；③ 成人内容中性技术表述。
