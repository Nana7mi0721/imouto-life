## ⑥ 写正文时的使用方式（含验收自检）

- 写「第 3 章 日常循环与行动全表」「第 10 章 效率路线与速通」「第 12 章 常见问题与体验优化」涉及随机处，2.1 / 2.2 / 2.4 / 2.7 逐行回指；**能写「存在随机分档、区间、权重结构」，不能写具体概率定论 / 抽序列 / 掉率 / 逐格条件**。凡 ⑤ 表 U / `◐` / `—` 项只写「资料不足/待核」并指向 `05`。
- **两套 G 值写法**：「攻略文档存在两套游戏概率数值（`20/40/50/30/30/30/20` 与 `30/50/70/40/40/40/30`）互相矛盾；脚本侧只有一组 7 连 `rand(1,10)` + `op111` 三档分档（`CE248@53..392` / `CE260@40..385`），与后者权重结构吻合；两套是否异作 / 旧版串入资料不足/待核」。
- **「不 pin」写法**：「给区间 / 分支结构 / 权重结构，不给『第 N 抽必得 X』或固定抽序列；`M7_PRNG.md §4` 的初始 cursor / 回绕 / 推进点 / 粒度 / 标题屏消耗均为 inferred-not-proven」。
- **三条铁律**：① 脚本值优先；② U 项不编造确切数字（概率 / 掉率 / 阈值 / 逐格条件 / 抽值序列）；③ 成人内容中性技术表述。
