# 结论摘要  

- **WOLF RPG Editor 版本及发布时间：** 官方下载页面显示，WOLF Editor 2.00 对应约 2011年07月19日，2.02（“2.02a”）约 2012年06月10日，2.10 约 2013年08月09日，2.20 约 2017年03月22日。大版本跳升：3.00 于 2022年11月22日发布（重大升级）。这些更新日志中部分提到 **游戏数据的格式变化**：例如 Ver2.10 起修改了加密方式。  
- **“基本システム Ver2.20” 模板：** 该模板是 WOLF Editor 附带的公共事件集，随 Ver2.20（2016/11/22 发布）更新引入，但官方未公开详细文档。具体脚本内容（编号0–211）未找到独立公开源，只能从旧版编辑器或社区资源中提取。  
- **2.00时代事件命令更新：** 官方更新日志表明 Ver2.10 变更了数据加密。其它命令语义变化（如150号图片显示、290号效果、102号选择窗口等）未在公开文档中提及，需结合开源解析器和实测。  
- **官方手册与术语：** 官方帮助文档列出了「ピクチャ（图片）」「ウィンドウ（窗口，如消息窗口和选项窗口）」「エフェクト（效果）」「選択肢ウィンドウ（选项窗口）」「変数/データベース」等术语，但无易查的公开翻译或完整说明。  
- **字体与文本：** Ver2.00时代默认使用系统 Shift-JIS 编码与内置位图字体，官方说明中对字符串编码及字体机制仅有零星提及。中文汉化通常替换 Editor.exe 内的默认字体或使用外部 TTF，但官方无具体指南。  
- **存档格式：** Ver2.10 起游戏存档和可执行文件的数据加密方式变更，旧版存档存在兼容性问题（如旧存档字体尺寸错误已在 Ver2.20 修正）。Ver2.00 世代存档结构在加密前后本质相同，但加密模式不同。  
- **现成开源工具：** `WolfDec` 可解密所有当前版本的 .wolf 文件；`UberWolf` GUI 工具支持新版；`WolfTL` 聚焦翻译提取（主要兼容新版数据）；`wolfrpg-map-parser` 等解析库对 3.x 支持较好，对 2.x 兼容性有限（暂无官方说明，应实测）。  

# 机制/流程 Step-by-Step  

1. **版本与数据格式演进：** 根据官方发布日志，WOLF RPG Editor 从 2.00 起在每个大版本更新中逐步增加新功能并修改数据格式。Ver2.10（2013年8月）引入新命令（如下载命令）并“游戏数据加密方式从 Ver2.10 起变更”。Ver2.20（2016年11月）进一步改进存档兼容性（修正了旧存档字体倍率错误）。Ver3.00（2022年11月）为超大规模更新，引入 Unicode 支持等。  
2. **“基本系统 Ver2.20”模板：** “基本系统”是内置的公共事件集合，用于游戏启动等基础逻辑。在 Ver2.20 更新日志可知，当时更新了系统变量、游戏设置等。实际脚本（Common 0号）一般包含基本循环逻辑，但官方未公开源代码。可通过下载旧版 “基本系统” 文件查看具体实现。  
3. **2.00时代命令语义变化：** 公开日志表明 Ver2.00→2.10 期间，部分命令和内部处理做了修正。例如 Ver2.10 修正了“文章显示/字符串操作”以及“变量操作+”等命令的行为。150号“图片显示/移动/消去”命令在旧版和新版中参数含义可能略有差异，但未在文档明确说明；290号“画面效果”命令参数表未知（WolfTL等工具仅列出效果种类）。命令102（选择支窗口）、130（场所移动）等在旧版手册中有简单描述，但参数细节需实测。125/126（输入禁止/自动输入）在日志中无变动说明，推测行为与现代版相同。  
4. **官方手册规范：** 官方手册（帮助文档）按版本提供了 “ピクチャ表示”“文章/文字列表示”“エフェクト”“選択肢ウィンドウ”“変数操作”“DB操作”等章节，描述了各命令使用。但目前仅有日文原文，且更新日志多为“更新说明”形式，缺少中文版术语对照。  
5. **字体和字符串：** 早期版本默认使用系统的 Shift-JIS 多字节编码，内置位图字体供显示。Ver2.10前后增加了简体/繁体中文支持选项。汉化时通常用 Resource DLL 或替换 Editor 内置字体（例如使用 Microsoft YaHei TTF）。手册“素材规格”中提到字体尺寸和unicode，但无明确加密方式说明。  
6. **存档结构变化：** Ver2.10 更新后，Game.exe 的加密算法改变，导致旧版加密的存档或数据文件在新版中无法直接使用。此外 Ver2.20 修正了“旧存档中文字大小”的兼容问题。Ver2.00 世代的存档结构（字段、字节顺序等）与 2.10 比较应保持一致，仅加密层不同。详尽格式可参考社区解析（如 wolfrpg-map-parser 等），但官方无公开说明。  
7. **开源工具支持：** - **WolfDec**：支持解密所有版本的 .wolf 文件（包括 WOLF Editor 2.x 和 3.x）。  
   - **UberWolf**：是 WolfDec 作者的 GUI 工具，亦支持当前所有版本文件。  
   - **WolfTL**：侧重翻译数据提取，主要针对新版游戏数据结构，文档未明示对 2.x 的支持；可尝试对 2.00 数据运行。  
   - **wolfrpg-map-parser** 等解析库：主要为现代版本开发，2.00 时代支持状况未知，可能需要适配。  
   已知这些工具中，WolfDec 明确兼容早期版本。其它工具若报错，则需人工调整或寻找社区补丁。

- **版本兼容性**：按官方日志，Ver2.10前后存档/加密有变化。Rust 引擎重写时，必须区分加密算法：可使用 WolfDec 等工具逆向或利用其开源代码了解解密流程。旧版存档对字体/编码有已知问题（Ver2.20修正），汉化时注意兼容。

- **字段和变量**：因无官方表，所有系统变量（如 `9000104/5`、`9000071/2` 等）及标志位应靠手头游戏脚本、存档或debug摸索。可以试用编辑器或通过读写系统变量命令测试值。避免简单假设，关键处以实测为准。
