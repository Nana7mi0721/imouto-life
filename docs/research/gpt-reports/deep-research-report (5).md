# 机制流程（step-by-step）  
1. **白天活动**：根据职业（学生/公司职员/自由职业/废柴）进行上班打工或学习，消耗行动力换取货币；周末可多3次自由行动。  
2. **下班/下学后**：可花钱购物（食材或饮品）。购买并使用饮料/便当等可回复行动力（例如普通食材+15行动力）或延长活动时间（喝咖啡延长到凌晨2点）。购买媚药等特殊药品可提升特定属性。  
3. **晚上独处**：21:00后强制洗澡，23/24点强制入睡（喝咖啡可延后至2点）。深夜23:30后（需保留≥21行动力）进入可操作时段，点击妹妹触发互动选项。这些互动（会话、看电视、玩游戏、烹饪、摸头等）消耗行动力，并按类型提升妹妹的信頼/興味。妹妹的心情（キゲン）在互动或夜袭后会随机波动，好心情时可额外提升信頼。  
4. **夜袭H环节**：当满足行动力和阈值条件时可进入H事件，进行亲密行为。行为过程中屏幕右下显示“射精感%”进度，累积到100%则妹妹高潮，影响信頼/興味变化。使用安全套等可防止妊娠；未使用则可能触发BAD END（着床）。  
5. **次日状态调整**：睡眠后清晨可查看结果。若妹妹睡眠状态降至“寝惚”（熟睡），则会降低信頼、增加興味。每天系统会自动降低興味。其他数值（日收入、好感等）根据前日操作已更新。系统检查各阈值：若达到条件则触发对应事件选项（如共浴、特殊CG等）。  
6. **重复循环**：如此日复一日。周末可安排额外活动（购物、室外活动等），满足特定条件会解锁新活动（如祭典、旅行等）。长期同居（例如100天）也会自动触发结局事件。
