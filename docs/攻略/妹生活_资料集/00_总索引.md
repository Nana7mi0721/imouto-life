# 《妹！生活 ～単色～》（Imouto! Life ~Monochrome~）资料集 · 00 总索引

> **适用版本**：简体中文零售版 **Ver2.03**（汉化显示副标题）；引擎 WOLF RPG Editor ver2.22；数据格式世代 2.00（V200）；`Data.wolf` DXArchive VER6。三个口径互不混称。
> **定位**：纯百科 / 数据手册。以表格和条目为主，每个条目配一句简明说明，不做剧情化攻略。
> **数据底稿**：仓库 `work/Data` 解包数据 + `docs/M3_*` 系列实测文档 + `work/out/_archive/reports/` 导出表（唯一数字来源）；正文数值尽量回到 `CE编号@槽位`、变量表或实测记录。
> **覆盖范围**：系统数值、物品、事件、角色、日程/结局、CG/相册/收集。
> **剧透**：全量剧透，直接写条件、分支和结局。
> **内容说明**：成人内容只做中性技术记录（场景名、触发条件、数值门槛、分支、CG 编号），不逐字收录露骨描写。

## 3. 统一字段规范

### 3.1 物品条目

| 字段 | 写法 |
|---|---|
| 编号 | 商店/物品栏槽位号；无脚本序号用 `X-01` |
| 名称 | 简中译名；括号内保留日文原名/常见别名 |
| 类别 | 茶饮/食品/药品/避孕/健身/安眠/游戏/情趣用品 |
| 价格 | 商店脚本价（`CE250`/`CE245` 字面量）；非卖品标"非卖品" |
| 效果 | 只写可验证的增量或状态；观测值标 `G` |
| 限制/备注 | 一次性、每日限购、重复购买无效等 |
| 获取 | 商店分区、事件、初始持有 |
| 证据 | `S/T/G/U`（见 §4） |

### 3.2 行动/事件条目

| 字段 | 写法 |
|---|---|
| 事件编号 | 优先 `CE212..303` 公共事件号 / `ev N` 地图事件号 |
| 名称 | 菜单名或事件标题 |
| 地点/时段 | 平日白天/周末/夜间/深夜/浴室/厕所等 |
| 前置 | 变量阈值、持有物、心情、星期、节日 |
| 选项/结果 | 每个选项的增量、分支、概率、一次性标记 |
| 证据 | 脚本坐标 + 判定等级 |

### 3.3 结局条目

| 字段 | 写法 |
|---|---|
| 结局名 | 零售中文标题 |
| 判定链 | 变量旗标 + 阈值 + 唯一写入者 |
| 演出 | CG 文件、staff roll、选项 |
| 相册 | 解锁的 album 格位 |
| 证据 | `S/T/G/U` |

## 4. 证据分级与符号

| 标记 | 含义 |
|---|---|
| `S` | 脚本一手：`CE编号@槽位` 的 op111/op150/op210 字面量、变量表行名 |
| `T` | 运行时实测：headless 冒烟断言、结局/相册 gating 实测、真实存档样本 |
| `G` | 社区攻略观测：可能取整、近似、定性 |
| `U` | 未验证 / 未定位：脚本找不到、资料矛盾或需实机确认 |
| `✅一致` | 脚本、实测、社区观测互相一致 |
| `以脚本为准` | 社区观测与脚本冲突时，正文写脚本值 |

> 关键语义：本作脚本用 `op111`（条件分支）做阈值门，`op150` 操作图片，`op102` 出选项。
> 多条件 AND 在脚本里表现为连续 `op111` 嵌套；正文统一记作"A≥x 且 B≥y"。
