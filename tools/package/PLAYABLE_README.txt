【怎么开始】
  双击本文件夹里的「Imouto Life.exe」即可，不需要命令行。
  启动后进入游戏标题画面，点击「开始游戏 / 继续游戏」即可游玩。

【文件夹说明】
  Imouto Life.exe      ← 双击这个
  runtime\wolf-cli.exe ← 游戏引擎（不要单独删除）
  Data\                ← 游戏数据（图片 / BGM / SE / 字体 / 存档）
  README.txt           ← 本说明

【操作】
  鼠标 / 方向键 / Enter / Z：选择与确认
  Esc：返回
  F9：切换缩放（窗口大小）
  F11：全屏切换
  F10：关闭游戏
  F12：重启

【存档】
  存档写入 Data\Save\。本包自带测试存档，可在标题画面载入；
  也可以直接开始新游戏。游戏内「保存」菜单可以打开存档界面。

【排查】
  如果双击没有反应：
  1. 确认整个文件夹是完整的（不要只复制 Imouto Life.exe）。
  2. 查看同目录的 launcher-error.log 或 game-log.txt。
  3. 需要 64 位 Windows；首次启动可能稍慢。
